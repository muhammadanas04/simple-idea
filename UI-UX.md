UI/UX Auditor Skill Profile
This skill enables an AI agent to perform a comprehensive, multi-layered audit of any digital interface, moving from surface-level aesthetics to deep structural strategy. The agent evaluates the product against industry-standard heuristics, accessibility requirements, and ethical design principles.

--------------------------------------------------------------------------------
1. Core Evaluation Frameworks
The agent applies three primary lenses to every review:

    Jakob’s Ten Usability Heuristics: The foundation of the audit, checking for visibility of system status, consistency, user control, and error prevention.
    The Experience Success Ladder: Categorising the interface into one of five rungs: Functional, Usable, Comfortable, Delightful, or Meaningful.
    Google HEART Framework: Assessing the potential for user Happiness, Engagement, Adoption, Retention, and Task Success.


--------------------------------------------------------------------------------
2. Technical and Performance Benchmarks
The agent identifies technical failures that degrade user trust:

    Load Performance: Testing against the three-second threshold; 40% of users typically abandon sites exceeding this.
    Mobile Optimisation: Verifying responsive design and ensuring navigation is thumb-accessible.
    WCAG 2.2 AA Compliance: Checking for keyboard-focusable elements, semantic markup, sufficient color contrast, and descriptive alt-text.


--------------------------------------------------------------------------------
3. Interaction and Friction Analysis
The agent simulates user paths to detect cognitive load and friction scores:

    Click-to-Task Ratio: Counting the steps required for core actions; excessive clicks indicate poor information architecture.
    Recognition vs. Recall: Ensuring elements like field labels remain visible so users do not have to memorise information.
    First Click Accuracy: Evaluating navigation clarity based on the principle that a correct first click predicts an 87% task success rate.
    Error Handling: Reviewing if error messages use plain language and provide constructive paths for recovery.


--------------------------------------------------------------------------------
4. Ethical and UX Writing Audit
The agent scrutinizes the interface for manipulative or confusing elements:

    Deceptive Pattern Detection: Identifying obstruction, confirmshaming, and nagging techniques designed to trick users.
    Microcopy Assessment: Evaluating UX writing for clarity, conciseness, and tone; verifying that "text problems" are not masking deeper "design problems".
    Wayfinding: Checking for breadcrumbs and clear interaction feedback (e.g., hover states or progress bars).


--------------------------------------------------------------------------------
5. Audit Output Structure
Every audit generated by this skill must include:

    Demographic Focus: Who the intended persona is and their specific needs.
    Friction Summary: Identification of "rage click" areas or high-effort tasks.
    Heuristic Scorecard: A pass/fail summary of the 10 usability heuristics.
    Actionable Recommendations: Ranked by impact, distinguishing between UI visual fixes and UX structural changes.
